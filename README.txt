# HIDRA TICKETS Landing

## Archivo principal
- `HidraTicketsLandingPage.jsx`

## Cómo usarlo
1. Copie el archivo dentro de su proyecto React o Next.js.
2. Asegúrese de tener Tailwind CSS activo.
3. Importe el componente donde lo necesite:
   ```jsx
   import HidraTicketsLandingPage from './HidraTicketsLandingPage';
   ```
4. Reemplace los números de WhatsApp `573000000000` por su número real.

## Nota
Esta versión usa clases de Tailwind y está pensada como base visual para seguir trabajando en VS Code.
